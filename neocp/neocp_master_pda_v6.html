1. Core Server & Network Configuration

Server Identity & IP Management Administrator Only

Base-level configurations mapping directly to OS network interfaces and resolver files.

IP Address Routing

  • Add IPv4 Addresses: Interface to bind new IPs to server network adapters (`eth0`, `ens33`).
  • Shared IP Pool: Configure the primary Shared IP that all default websites will map to via NGINX/Apache virtual hosts.

3. Package Creation & Quota Enforcement

Granular Resource Packaging Admin Reseller

Resource Limits

  • Disk Space Quota: Supports MB/GB/TB or "unlimited".
  • Monthly Bandwidth Limit: Network transit caps.
  • Max Counts (Numeric/Unlimited): FTP Accounts, Email Accounts, SQL Databases, Sub Domains, Parked Domains, Addon Domains.

Email & Security Quotas

  • Hourly Email Relay Limit: Hard cap on outbound emails per domain.

Package Settings & Extensions

  • Dedicated IP Options: Restricted for Resellers, configurable by Admins.
  • Access Toggles: Shell Access, CGI Access, Digest Authentication.
  • Locale Support: Multi-language package defaults (allows users to select preferred languages from surveyed availability).
  • WHMReseller Extension: Automatically elevate a provisioned account to Reseller status upon creation.
